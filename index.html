ทบทวนความรู้เรื่องเลขยกกำลัง

Exponents Review • พื้นฐานสำคัญก่อนเรียนฟังก์ชันเอกซ์โพเนนเชียล

บททบทวน 00

1. ความหมายของเลขยกกำลัง

เลขยกกำลังเป็นการเขียนแทนการคูณจำนวนเดียวกันซ้ำ ๆ โดยมีรูปทั่วไปดังนี้

an = a × a × … × aคูณ a ทั้งหมด n ตัว

เรียก a ว่า ฐาน (Base) และ n ว่า เลขชี้กำลัง (Exponent)

ตัวอย่าง

34 = 3 × 3 × 3 × 3 = 81

ฐานคือ 3 และเลขชี้กำลังคือ 4

2. ชนิดของเลขชี้กำลัง

จำนวนเต็มบวก23 = 8คูณฐานซ้ำ 3 ตัว
เลขชี้กำลังศูนย์50 = 1เมื่อฐานไม่เท่ากับศูนย์
จำนวนเต็มลบ2−3 = 1/8เขียนเป็นส่วนกลับของกำลังบวก
เศษส่วน81/3 = 2สัมพันธ์กับรากที่ n

3. สมบัติของเลขยกกำลัง

เมื่อ a และ b เป็นจำนวนที่เหมาะสมตามเงื่อนไขของแต่ละสมบัติ และ m, n เป็นจำนวนเต็ม จะได้ว่า

01
การคูณเลขยกกำลังฐานเดียวกันam × an = am+n
02
การหารเลขยกกำลังฐานเดียวกันam ÷ an = am−n (a ≠ 0)
03
กำลังของเลขยกกำลัง(am)n = amn
04
กำลังของผลคูณ(ab)n = anbn
05
กำลังของผลหาร(a/b)n = an/bn (b ≠ 0)
06
เลขชี้กำลังศูนย์a0 = 1 (a ≠ 0)
07
เลขชี้กำลังเป็นจำนวนเต็มลบa−n = 1/an (a ≠ 0)
08
เลขชี้กำลังเป็นเศษส่วนam/n = n√(am)
ข้อควรจำ
การคูณและการหารจะรวมเลขชี้กำลังได้เมื่อฐานเหมือนกันเท่านั้น และห้ามหารด้วยศูนย์

4. ตัวอย่างการใช้สมบัติ

ตัวอย่างที่ 1

23 × 24 = 23+4 = 27 = 128

คูณฐานเดียวกัน จึงนำเลขชี้กำลังมาบวกกัน
ตัวอย่างที่ 2

35 ÷ 32 = 35−2 = 33 = 27

หารฐานเดียวกัน จึงนำเลขชี้กำลังมาลบกัน
ตัวอย่างที่ 3

4−2 = 1/42 = 1/16

เลขชี้กำลังติดลบ เปลี่ยนเป็นส่วนกลับ
✎

สรุปจำง่าย

คูณฐานเหมือนกัน → บวกเลขชี้กำลัง

หารฐานเหมือนกัน → ลบเลขชี้กำลัง

ยกกำลังซ้อนนำเลขชี้กำลังมาคูณกัน

กำลังลบเปลี่ยนเป็นส่วนกลับ

กำลังศูนย์มีค่าเท่ากับ 1 เมื่อฐานไม่เป็นศูนย์

◎

ลองคิดก่อนเรียนต่อ

1) 22 × 23 มีค่าเท่าใด?

ดูแนวคำตอบ

25 = 32 เพราะคูณฐานเดียวกันให้นำเลขชี้กำลังมาบวกกัน

2) 10−2 เขียนเป็นเศษส่วนได้อย่างไร?

ดูแนวคำตอบ

1/102 = 1/100

3) (32)3 มีค่าเท่าใด?

ดูแนวคำตอบ

36 = 729 เพราะนำเลขชี้กำลังมาคูณกัน

พร้อมแล้วหรือยัง?
เมื่อเข้าใจสมบัติเลขยกกำลังแล้ว ไปเรียนรู้ฟังก์ชันที่มีตัวแปรอยู่บนเลขชี้กำลังกันต่อได้เลย

LESSON 01 / EXPONENTIAL

ฟังก์ชันเอกซ์โพเนนเชียล

Exponential Function

บทเรียนที่ 1

ความหมายของฟังก์ชันเอกซ์โพเนนเชียล

ฟังก์ชันเอกซ์โพเนนเชียล คือ ฟังก์ชันที่เขียนได้ในรูป

f(x) = axเมื่อ a > 0 และ a ≠ 1

โดย a เรียกว่า ฐาน (Base) และ x เป็นเลขชี้กำลัง ซึ่งเป็นตัวแปร

จำให้แม่น!
ฐานต้องเป็นจำนวนจริงบวก และต้องไม่เท่ากับ 1

ลักษณะกราฟ

เปรียบเทียบกราฟเมื่อฐานต่างกัน a > 1 0 < a < 1

กราฟทั้งสองผ่านจุด (0, 1) และมีเส้นกำกับแนวนอน y = 0

สมบัติที่ควรรู้

  • โดเมนเป็นจำนวนจริงทั้งหมด
  • เรนจ์เป็นจำนวนจริงบวก (y > 0)
  • กราฟผ่านจุด (0, 1)
  • ถ้า a > 1 กราฟเป็นฟังก์ชันเพิ่ม
  • ถ้า 0 < a < 1 กราฟเป็นฟังก์ชันลด

LESSON 02 / LOGARITHM

ฟังก์ชันลอการิทึม

Logarithmic Function

บทเรียนที่ 2

ความหมายของลอการิทึม

ลอการิทึมเป็นการเขียนอีกแบบหนึ่งของเลขยกกำลัง ใช้ตอบคำถามว่า “ต้องยกกำลังฐานเท่าใด จึงจะได้ผลลัพธ์ที่กำหนด”

loga x = yก็ต่อเมื่อ ay = x

เมื่อ a > 0, a ≠ 1 และ x > 0

ตัวอย่าง

เพราะ 23 = 8 ดังนั้น log2 8 = 3

อ่านว่า ลอการิทึมฐาน 2 ของ 8 มีค่าเท่ากับ 3

สมบัติของลอการิทึม

ผลคูณloga(MN) = logaM + logaN
ผลหารloga(M/N) = logaM − logaN
เลขชี้กำลังloga(Mr) = r logaM
เปลี่ยนฐานlogaM = logbM / logba
ข้อควรระวัง
จำนวนที่อยู่ภายในเครื่องหมายลอการิทึมต้องเป็นจำนวนจริงบวกเท่านั้น

ความสัมพันธ์ของฟังก์ชันทั้งสอง

ฟังก์ชันเอกซ์โพเนนเชียลและฟังก์ชันลอการิทึมเป็นฟังก์ชันผกผันกัน กราฟจึงสะท้อนกันบนเส้นตรง y = x

ay = x ⇄ loga x = y
เอกซ์โพเนนเชียล ↔ ลอการิทึม
