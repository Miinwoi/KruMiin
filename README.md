# ฟังก์ชันเอกซ์โพเนนเชียลและฟังก์ชันลอการิทึม ม.5 — By Kru Miin

เว็บไซต์บทเรียนแบบ Static ใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้งเซิร์ฟเวอร์หรือฐานข้อมูล

## ไฟล์
- `index.html` หน้าเว็บไซต์หลัก
- `style.css` รูปแบบและ Responsive Layout
- `script.js` ระบบแบบทดสอบ ตรวจคำตอบ คำนวณคะแนน และเฉลย
- `assets/` สำหรับเก็บสื่อประกอบเพิ่มเติม

## เปิดทดสอบในเครื่อง
1. ดาวน์โหลดและแตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `kru-miin-exponential-log`
3. ดับเบิลคลิก `index.html` เพื่อเปิดในเบราว์เซอร์
4. ทดลองเมนูนำทางและแบบทดสอบให้ครบทุกข้อ

## เผยแพร่ผ่าน GitHub Pages
1. ลงชื่อเข้าใช้ GitHub แล้วสร้าง Repository ใหม่ เช่น `kru-miin-math-m5`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมด โดยให้ `index.html` อยู่ที่ระดับบนสุดของ Repository
3. ไปที่ **Settings → Pages**
4. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก Branch `main` และ Folder `/ (root)` แล้วกด **Save**
6. รอ GitHub Pages เผยแพร่ แล้วเปิด URL ที่ GitHub แสดงในหน้า Pages

## หมายเหตุ
- เว็บไซต์ไม่ใช้ PHP, MySQL หรือ Backend
- แบบทดสอบทำงานในเบราว์เซอร์ คะแนนไม่ถูกส่งหรือบันทึกไปยังฐานข้อมูล
- ฟอนต์ Google Fonts ต้องเชื่อมต่ออินเทอร์เน็ต หากออฟไลน์จะใช้ฟอนต์สำรอง
